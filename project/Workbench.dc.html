TouchKit Workbenchv0.1
The IDE scaffold layer — thread sidebar, MessageScroller chat, resizable terminal, surface panel with full-screen mode. Chat markdown streams through docstream. Read the docs · phone demo
FRAME
Try: send a message — the reply streams as markdown and the new turn anchors near the top · scroll up mid-stream, then use the jump pill · open a surface in the right panel and hit expand for full screen · drag the terminal's top edge · at Tablet width the surface panel becomes a right-edge drawer; at Phone width the sidebar is a hamburger, the terminal a vaul drawer, and surfaces live in a bottom tab bar — tap one to focus it.
Adaptive regions
sidebar   column → hamburger drawer
terminal  bottom dock → vaul snap sheet
panel     column → drawer → bottom tab bar
One tree, three presentations — the shell measures its own width, so the FRAME switch above exercises every mode.
