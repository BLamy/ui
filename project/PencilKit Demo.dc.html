TouchKit PencilKitv0.1
A drawing surface on perfect-freehand — pressure-thinned pen, translucent marker, tapered pencil, stroke eraser. Read the docs · phone demo · workbench
FRAME
Try: draw slow then fast — speed and pressure thin the pen · marker overlaps build up like real ink · the eraser removes whole strokes it touches · every palette pick lands a selection tick.
The pipeline
pointer [x, y, pressure]
  → getStroke(points, options)
  → outline polygon
  → one filled SVG path
No per-segment strokes — the whole mark is a single outline, so joins, tapers, and pressure bulges are geometrically exact.
Tool tuning
pen     size 7   thinning .62
marker  size 20  thinning .06  50% alpha
pencil  size 4.5 thinning .72  taper 22
eraser  hit-tests + removes strokes
Mouse and touch get simulated pressure from velocity; Apple Pencil reports the real thing. Coalesced events keep fast strokes dense.
