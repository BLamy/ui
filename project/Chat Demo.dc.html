TouchKit ChatKitv0.1
A team-chat scaffold with full threads — every thread opens in a real TouchKit SideDrawer (docked column when wide, overlay sheet when not). Read the docs · Workbench demo
FRAME
Try: pick a thread in the channel column — it opens full-view (with “Open as drawer”) · click a thread preview card under a message for the SideDrawer · hover any message to react or start a new thread · at Phone width the channel column becomes a hamburger drawer.
Original design in TouchKit's dark language — the thread panel is the same SideDrawer the Contacts demo uses, in both of its modes.
